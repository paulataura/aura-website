# Aura Solutions Group website (aurasolutions.co.uk)

Master copy of the live site, taken 29 October 2026, plus drafts.

- Root folder: the live site exactly as published on IONOS (plain HTML, `styles.css`, `script.js`, `assets/`).
- `drafts/`: work in progress not yet live (e.g. `asset-management-v3.html`, the ChatGPT-era Asset Management redesign).

To preview locally: run `python3 -m http.server` in this folder and open http://localhost:8000.
